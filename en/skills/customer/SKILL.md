## 01. Persona
**Purpose**: Portray the typical target customer as a concrete person so the whole team shares an understanding of "who we are building this for"

**When to use**: At the planning stage of a new business, when renewing an existing service, when planning marketing initiatives. Especially effective when you sense that team members have different pictures of the customer.

**Template**:
| Item | Content |
|------|-----|
| Name (pseudonym) | |
| Age / gender | |
| Occupation / title | |
| Annual income / family | |
| Residence / lifestyle | |
| Values / beliefs | |
| Challenges / worries | |
| Information sources | |
| Purchase decision criteria | |
| Frequently used services | |
| Daily timeline | |
| Technology literacy | |

**How to use**: Build it on real data (interviews, surveys, behavior logs, etc.). A persona built from imagination alone misses the mark. Two to three personas per business is appropriate. Too many blurs the focus.

### Worked example (B2C service)
| Item | Content |
|------|-----|
| Name (pseudonym) | Misaki Tanaka |
| Age / gender | 32, female |
| Occupation / title | Project manager at an IT company (mid-level) |
| Annual income / family | Annual income 5.5 million yen. Lives with her husband (35, systems engineer), no children |
| Residence / lifestyle | Setagaya, Tokyo. Busy on weekdays, gets home around 21:00. On weekends she relaxes at cafes or has brunch with friends |
| Values / beliefs | "Time matters more than money." Efficiency-focused, but particular about quality when choosing products. Interested in sustainable consumption |
| Challenges / worries | No time to shop on weekdays. Many failed purchases when buying online. Wants to find things that suit her efficiently |
| Information sources | Instagram, word of mouth from friends, Google search, YouTube |
| Purchase decision criteria | Review ratings, time savings, good design, whether the brand is trustworthy |
| Frequently used services | Amazon Prime, Uber Eats, Netflix, Mercari |
| Daily timeline | 7:00 wake up → 8:30 arrive at work → 12:00 lunch (at desk) → 21:00 get home → 22:00 onward free time → 24:00 bed |
| Technology literacy | High. Tries new apps without hesitation |

### Worked example (B2B service)
| Item | Content |
|------|-----|
| Name (pseudonym) | Kentaro Suzuki |
| Age / gender | 45, male |
| Occupation / title | Head of corporate planning at a mid-sized manufacturer |
| Annual income / family | Annual income 9 million yen. Wife and two high-school-aged children |
| Residence / lifestyle | Saitama City, Saitama. Commutes by car. Attends an industry association study group once a month |
| Values / beliefs | Values "data-driven decision making." Tasked with driving digital transformation in the company but struggles with resistance from the front line |
| Challenges / worries | Improving business processes that depend on individuals, explaining return on investment to executives, low adoption rates after tool rollouts |
| Information sources | Nikkei Business, industry trade journals, trade shows, LinkedIn articles, case studies from peer companies |
| Purchase decision criteria | Clear ROI, track record of deployments, support structure, integration with existing systems |
| Frequently used services | Salesforce, kintone, Teams, SAP |
| Daily timeline | 6:30 wake up → 8:00 arrive at work → 3 to 4 meetings → 18:30 get home → dinner → 21:00 onward email → 23:00 bed |
| Technology literacy | Moderate. Good with Excel but unfamiliar with the latest SaaS tools |

### Common mistakes
1. **Fantasy persona**: Drawing the "ideal customer we wish we had" without real data. The result is a persona disconnected from actual customers
2. **Persona sprawl**: Greedily creating five or more personas to cover "this customer and that customer too," so none of them ends up in focus
3. **Build it and forget it**: Stopping at the satisfaction of having made a persona, which then never gets referenced in decision making. You need a routine for daily use, such as posting it on the wall or reviewing it at the start of meetings

### Tips
- **Interview at least 5 people**: Quantitative data is not enough. Qualitative research that digs into "why do you do that" with real customers is essential
- **Update regularly**: Markets and customers change. Review the persona once every six months to a year
- **Create a negative persona too**: Clearly defining "this person is not our target" makes it easier to choose which initiatives to pursue
- **Add a photo or illustration**: Visual elements deepen shared understanding within the team

- **Customer Journey Map** (`/customer` 03) to design the persona's experience over time
- **Jobs to Be Done (JTBD)** (`/customer` 04) to identify the job the persona really wants to get done
- **STP** (`/customer` 07) to validate the target segment

## 02. Empathy Map
**Purpose**: Capture the customer's inner world (thoughts, feelings) and outer world (behavior, environment) from six perspectives, and understand the fundamental desires behind surface-level needs

**When to use**: For deeper exploration after creating a persona, in the early stages of UX design, when you want to discover improvements to an existing service from the customer's point of view

**Template**:
| Perspective | Content |
|------|-----|
| **Think & Feel** (what they think and feel) | |
| **See** (what they see) | |
| **Hear** (what they hear) | |
| **Say & Do** (what they say and do) | |
| **Pain** (pains and frustrations) | |
| **Gain** (what they want to gain, their wishes) | |

**How to use**: Use together with a persona. Consider your own value proposition by following the flow from Pain to Gain. Running it as a team workshop is effective. Use sticky notes to generate ideas for each perspective and discuss them.

### Worked example (office worker in their 30s using an online English conversation service)
| Perspective | Content |
|------|-----|
| **Think & Feel** | "If I can't speak English my career will plateau." "But I'm too busy to attend a school." "I'm not sure I'll really improve." "I feel anxious that my colleagues are handling overseas projects" |
| **See** | Colleagues holding meetings in English, friends' social media posts enjoying overseas trips, ads for English learning apps, an internal notice listing a TOEIC score as a promotion requirement |
| **Hear** | From the boss: "The next project requires English." From a friend: "Online English conversation was great." Online ad copy: "Speak in just 15 minutes a day" |
| **Say & Do** | Says "I'll start next month" but keeps putting it off. Signs up for free trials but doesn't continue. Listens to podcasts during the commute but can't concentrate. Buys TOEIC study books that pile up unread |
| **Pain** | Self-loathing for not sticking with it, the hassle of scheduling, anxiety about not knowing whether a tutor will be a good fit, impatience because results are hard to see, doubts about cost-effectiveness |
| **Gain** | Wants to speak confidently on overseas business trips, wants to advance their career, wants to make foreign friends, wants self-confidence, wants to be recognized as "someone who can speak English" |

### Common mistakes
1. **Staying at a surface-level description**: "Wants to learn English" is not usable until you dig into "why do they want to learn" and "what happens if they can't"
2. **Bias toward your own company's convenience**: Interpreting things in a way that suits your company, as in "they surely think this way." Base it on real customer voices
3. **Confusing Pain and Gain**: Pain is current frustration or suffering. Gain is the ideal state. "I want it cheaper" is a Pain. "I want to improve cost-effectively" is a Gain

### Tips
- **Create it right after customer interviews**: Write down the exact words you heard while the memory is fresh
- **Pay attention to contradictions between "Say & Do" and "Think & Feel"**: Where what people say differs from what they do, the real insight is hiding
- **Write multiple items in each cell**: List 3 to 5 bullet points. One item alone is shallow
- **Create it with the whole team**: When members with different customer touchpoints such as sales, development and customer success take part, the map becomes multi-faceted

### Next steps
- **Jobs to Be Done (JTBD)** (`/customer` 04) to structure Pains and Gains as jobs
- **Customer Journey Map** (`/customer` 03) to identify when Pains occur
- **Value Proposition Canvas** (`/strategy`) to design the value offered in response to Pains and Gains

## 03. Customer Journey Map
**Purpose**: Visualize over time the experience a customer has from first encountering a product or service through purchase, use and recommendation, and identify the touchpoints to improve

**When to use**: When you want a bird's-eye view of the whole customer experience, when you want to identify drop-off points, when you want to share "the customer's end-to-end experience" across departments

**Template**:
| Phase | Awareness | Interest / consideration | Purchase / contract | Use | Recommend / continue |
|---------|-----|----------|----------|-----|----------|
| Actions | | | | | |
| Touchpoints | | | | | |
| Thoughts | | | | | |
| Emotions (😊😐😟) | | | | | |
| Issues / opportunities | | | | | |
| Responsible department | | | | | |
| KPI | | | | | |

**How to use**: The troughs of the emotion curve (pain points) are the top priority for improvement. Phases can be customized to fit the business.

### Worked example (subscription fitness app)
| Phase | Awareness | Interest / consideration | Purchase / contract | Use | Recommend / continue |
|---------|-----|----------|----------|-----|----------|
| Actions | Sees an Instagram ad. Learns about it from a friend's social media post | Reads reviews in the app store. Signs up for the free trial | Chooses the monthly plan. Registers a credit card | Works out 3 times a week. Logs body weight | Refers friends. Switches to the annual plan |
| Touchpoints | Social media ads, word of mouth, Google search | App Store, landing page, comparison sites | In-app payment screen | App home screen, push notifications, Apple Watch integration | Referral program, email, in-app pop-ups |
| Thoughts | "I haven't been exercising lately." "A lot of people use this app" | "Will I really keep it up?" "How is it different from other apps?" | "I'll decide during the free period." "At 980 yen a month I'll give it a try" | "I did it again today!" "The menu is getting monotonous" | "I should tell my friends." "The annual plan saves two months' worth" |
| Emotions | 😐 Slightly anxious | 🤔 Hope and hesitation | 😊 Decided | 😊→😐 Gradually getting stale | 😊 Satisfied, attached |
| Issues / opportunities | Ad messaging is all about "losing weight" and not differentiated | Free trial flow is complicated, 30% drop-off rate | High drop rate on the payment screen (security concerns) | There is a "wall" where usage frequency drops in week 3 | Low awareness of the referral program |
| Responsible department | Marketing | Marketing, Product | Product, Customer Success | Product, Content | Growth, Customer Success |
| KPI | Ad CTR, awareness survey | Trial sign-up rate, landing page CVR | Paid conversion rate | WAU, retention rate (Day 7/30) | NPS, number of referrals, LTV |

### Common mistakes
1. **Drawing it from the company's point of view**: It turns into a process diagram of "what we do" and the customer's actual experience is lost. Keep the customer's actions and emotions at the center
2. **Phases are too coarse**: Don't settle for a single word like "purchase." Break it down into the actual steps, such as "compare → inquire → quote → internal approval → contract" (especially in B2B)
3. **Drawing only the ideal journey**: Map the current state (As-is) accurately before designing the ideal (To-be). Jumping straight to the ideal overlooks today's problems

### Tips
- **Use large paper (flip chart) or Miro**: Digital tools make collaborative editing easier
- **Attach real data**: Adding quantitative data such as conversion rates per phase, inquiry contents and NPS scores makes the map more persuasive
- **Always draw the emotion curve**: Don't stop at text. Visualize the ups and downs of emotion as a line graph
- **Create it with all related departments**: When marketing, sales, customer success and development come together, the "gaps" between phases become visible

### Next steps
- **Empathy Map** (`/customer` 02) to dig into the inner world of customers at the emotional troughs
- **Problem discovery and definition frameworks** (`/problem`) to analyze the root causes of the issues identified
- **Process improvement and optimization frameworks** (`/improvement`) to design improvement initiatives for touchpoints
- **Goal setting and execution management frameworks** (`/execution`) to set KPIs and manage the improvements

## 04. Jobs to Be Done (JTBD)
**Purpose**: Discover true needs by focusing on the "job" the customer wants to get done. Competitors are not only companies in the same industry but "every alternative that gets the same job done"

**When to use**: New product development, analyzing why an existing product isn't selling, when you can't find a point of differentiation from competitors, when exploring the direction of innovation

**Template**:
| Item | Content |
|------|-----|
| **Situation (When...)** | In what situation |
| **Motivation (I want to...)** | What they want to do |
| **Expected outcome (So that...)** | What they want to become |

**Types of jobs**:
- Functional job (practical purpose):
- Emotional job (how they want to feel):
- Social job (how they want to be seen by others):

**Job constraints**:
- Current solution (existing alternatives):
- Frustrations with the current solution:
- Barriers to switching:

**How to use**: Take the view that "the customer doesn't want a drill, they want a hole." Going further, "they don't want a hole, they want to mount a shelf on the wall." Focus on the job, not the existing solution.

### Worked example (business chat tool)
| Item | Content |
|------|-----|
| **Situation (When...)** | When working on tasks with team members while working remotely |
| **Motivation (I want to...)** | Want to exchange quick checks and consultations fast, without the formality of email |
| **Expected outcome (So that...)** | Can maintain decision-making speed and keep the team's sense of unity |

**Types of jobs**:
- Functional job: Communicate in real time via text, files and screen sharing
- Emotional job: Want the reassurance of being connected to the team without feeling isolated
- Social job: Want to be seen as "quick to respond = good at the job"

**Job constraints**:
- Current solution: Email, phone, in-person meetings
- Frustrations with the current solution: Email replies are slow. Phone calls feel intrusive when you consider the other person's schedule. Meetings take time to set up
- Barriers to switching: Pointless unless the whole team uses the same tool. Data migration is a hassle

### Common mistakes
1. **Confusing the solution with the job**: "I want to use Slack" is not a job. "I want to share information with my team quickly" is the job. Write the purpose, not the means
2. **Job granularity is too coarse**: "I want to be more efficient at work" is too abstract to use. Be as specific as "I want to approve a quote instantly while out of the office"
3. **Ignoring emotional and social jobs**: Analyzing only the functional job leads to a "spec war." Emotional and social factors strongly influence actual purchase decisions

### Tips
- **Ask "why did you switch"**: Asking existing customers "what did you use before and why did you switch" brings the job into sharp relief
- **"Reasons for rejection" are a gold mine too**: Interviewing people who considered but didn't buy reveals mismatches between the job and the solution
- **Write it as a job story**: Summarizing it in one sentence, "When (situation), I want to (motivation), so that I can (expected outcome)," makes it easy to use
- **Forces of Progress**: Analyzing the four elements "pull of the new solution" and "push of the current situation" vs "anxiety about switching" and "attachment to the status quo" shows why customers do or don't move

### Next steps
- **Persona** (`/customer` 01) to flesh out the person who has the job
- **Idea generation and evaluation frameworks** (`/idea`) to generate new solutions for the job
- **Strategy and business model design frameworks** (`/strategy`) to design a differentiation strategy based on the job
- **Value Proposition Canvas** (`/strategy`) to map the job to the value offered

## 05. Pareto Analysis (ABC Analysis)
**Purpose**: Identify the few factors that generate most of the overall results, and clarify priorities for resource allocation (the 80:20 rule)

**When to use**: Analyzing sales composition, optimizing inventory management, reviewing the customer portfolio, identifying cost reduction targets, prioritizing inquiry types

**Template**:
| Rank | Item | Value | Share | Cumulative share | Class |
|-------|------|-----|-------|----------|------|
| 1 | | | | | A |
| 2 | | | | | A |
| 3 | | | | | B |
| ... | | | | | C |

**Classification criteria**: A (cumulative up to 70%), B (up to 90%), C (up to 100%)

**Approach for each rank**:
| Class | Typical proportion | Approach |
|------|---------|---------|
| A | 20% of items account for 70% of the total | Most important. Intensive management and investment. Individual handling |
| B | 30% of items account for 20% of the total | Important. Standard management. Room for efficiency gains |
| C | 50% of items account for 10% of the total | Low priority. Simplify, automate, or in some cases withdraw |

### Worked example (sales analysis by product for an e-commerce site)
| Rank | Product | Monthly sales (10,000 yen) | Share | Cumulative share | Class |
|-------|--------|---------------|-------|----------|------|
| 1 | Premium serum | 450 | 25.0% | 25.0% | A |
| 2 | Organic shampoo | 320 | 17.8% | 42.8% | A |
| 3 | Moisturizing cream | 250 | 13.9% | 56.7% | A |
| 4 | UV protection milk | 200 | 11.1% | 67.8% | A |
| 5 | Lip balm | 150 | 8.3% | 76.1% | B |
| 6 | Hair oil | 120 | 6.7% | 82.8% | B |
| 7 | Hand cream | 80 | 4.4% | 87.2% | B |
| 8 | Body soap | 60 | 3.3% | 90.6% | C |
| 9 | Bath additives | 50 | 2.8% | 93.3% | C |
| 10 onward | 12 other products | 120 | 6.7% | 100.0% | C |

**Analysis result**: The top 4 products (18% of all 22 products) account for 67.8% of sales. Advertising budget and landing pages should be concentrated on these A-class products.

### Common mistakes
1. **Only one analysis axis**: Analyzing by sales amount alone overlooks products with high margins or future potential. Verify across multiple axes such as sales, profit and growth rate
2. **Cutting C-class items immediately**: Some C-class products are "entry products" that lead to purchases of A-class products, or "assortment products" that contribute to customer satisfaction
3. **Being satisfied with a single analysis**: Because of seasonal variation and market change, update it regularly (monthly or quarterly)

### Tips
- **Cross ABC analysis**: Build a matrix on two axes, sales × profit margin, and vary the initiatives by combination such as "sales A × profit A" and "sales A × profit C"
- **Draw a Pareto chart**: Overlaying a bar chart (individual values) and a line graph (cumulative ratio) makes the 80:20 relationship visible at a glance
- **Adjust the classification criteria to the business**: 70/90/100% is a guideline. Depending on the number of items handled and the nature of the business, 60/85/100% or similar may be better

### Next steps
- **RFM Analysis** (`/customer` 06) to further analyze the behavior patterns of A-class customers
- **Strategy and business model design frameworks** (`/strategy`) to build a strategy centered on A-class products and customers
- **Process improvement and optimization frameworks** (`/improvement`) to consider streamlining and automating C-class work

## 06. RFM Analysis
**Purpose**: Segment customers by three purchasing behavior metrics (Recency, Frequency, Monetary) and design the optimal approach for each segment

**When to use**: Designing CRM initiatives, segmenting email and direct mail campaigns, detecting early signs of customer churn, selecting targets for loyalty programs

**Template**:
| Customer | Recency (last purchase date) | Frequency (purchase frequency) | Monetary (purchase amount) | Score | Segment |
|------|-------------------|-------------------|-------------------|-------|----------|
| | High/Mid/Low | High/Mid/Low | High/Mid/Low | | |

**Scoring example** (each metric rated on a 5-point scale):
| Score | Recency | Frequency | Monetary |
|-------|---------|-----------|----------|
| 5 | Within 7 days | 2+ times a month | 100,000 yen or more per year |
| 4 | Within 30 days | Once a month | 50,000 to 100,000 yen per year |
| 3 | Within 90 days | Once every 3 months | 30,000 to 50,000 yen per year |
| 2 | Within 180 days | Once every 6 months | 10,000 to 30,000 yen per year |
| 1 | Over 180 days | Less than once a year | Under 10,000 yen per year |

**Representative segments and initiatives**:
| Segment | R | F | M | Characteristics | Recommended initiatives |
|-----------|---|---|---|------|---------|
| Best customers | High | High | High | Loyal customers | VIP perks, exclusive offers, co-creation programs |
| Good customers | High | High | Mid | Regulars with lower spend | Upselling, bundle sales |
| At risk of churn | Low | High | High | Former top customers drifting away | Immediate recovery measures (special coupons, direct contact) |
| Promising newcomers | High | Low | Low | Recently made first purchase | Onboarding, encourage second purchase |
| Dormant customers | Low | Low | Low | No activity for a long time | Reactivation campaign or remove from list |

### Worked example (customer segment analysis for an apparel e-commerce site)
| Customer ID | R (last purchase) | F (times per year) | M (annual amount) | R score | F score | M score | Segment |
|--------|------------|------------|------------|--------|--------|--------|----------|
| C001 | 3 days ago | Twice a month | 180,000 yen | 5 | 5 | 5 | Best customer |
| C002 | 15 days ago | Once a month | 60,000 yen | 4 | 4 | 4 | Good customer |
| C003 | 200 days ago | Formerly once a month | 120,000 yen | 1 | 4 | 5 | At risk of churn |
| C004 | 5 days ago | First purchase | 8,000 yen | 5 | 1 | 1 | Promising newcomer |
| C005 | 300 days ago | Once a year | 5,000 yen | 1 | 1 | 1 | Dormant customer |

### Common mistakes
1. **Not adjusting score thresholds to the industry**: Real estate (rarely bought more than once a year) and daily goods e-commerce have completely different Frequency and Recency thresholds. Set them to match your own purchase cycle
2. **Same initiative for every segment**: "10% off coupon for everyone" lowers margins on your best customers and has no effect on dormant ones. Segment-specific initiatives are essential
3. **Overweighting Monetary**: Looking only at amount puts "occasional big spenders" at the top, but customers with high Frequency often have higher LTV

### Tips
- **Prioritize R (Recency) first**: The more recent the last purchase, the higher the probability of the next one. If you want quick results, filter by R first
- **Give top priority to customers at risk of churn**: Customers with RFM "Low, High, High" are a sign that a former VIP is drifting away. Investigate the reason and respond personally
- **Track movement between segments**: Update RFM monthly and use the transition rate from "promising newcomer → good" and "good → at risk of churn" as KPIs
- **Combine with LTV (customer lifetime value)**: Looking at the correlation between RFM scores and LTV enables more precise investment decisions

### Next steps
- **Pareto Analysis** (`/customer` 05) to quantify the sales contribution of each segment
- **Customer Journey Map** (`/customer` 03) to visualize the experience of customers at risk of churn and identify the causes of drop-off
- **Goal setting and execution management frameworks** (`/execution`) to set KPIs per segment and manage the effect of initiatives

## 07. STP
**Purpose**: Segment the market (S), choose the target where you can win most (T), and establish a position differentiated from competitors (P). The framework that sets the skeleton of a marketing strategy

**When to use**: Market entry strategy for a new business, rebranding an existing business, when differentiation from competitors is vague, when considering a change of target

**Template**:

**Segmentation**:
| Dimension | Segment 1 | Segment 2 | Segment 3 |
|-------|-----------|-----------|-----------|
| Geographic | | | |
| Demographic | | | |
| Psychographic | | | |
| Behavioral | | | |

**Targeting**:
- Selected segment:
- Reason for selection:
- Market size:
- Growth potential:
- Competitive situation:
- Fit with own strengths:

**Types of targeting strategy**:
| Strategy | Description | When it applies |
|------|------|---------|
| Undifferentiated | Same product and message for the whole market | Commodity products (salt, sugar, etc.) |
| Differentiated | Optimized separately for multiple segments | Large companies running multiple brands |
| Concentrated | Specialized in a single segment | Startups with limited resources |
| Micro | Customized at the individual level | D2C, personalized services |

**Positioning**:
- Point of differentiation:
- Positioning statement: "For (target), (brand) is the only (category) that offers (point of differentiation), because (evidence)."

### Worked example (premium dog food brand)

**Segmentation**:
| Dimension | Segment 1: Health-conscious owners | Segment 2: Value-focused owners | Segment 3: Senior dog owners |
|-------|-------------------------|--------------------------|------------------------|
| Geographic | Urban areas (Tokyo, Osaka, Nagoya) | Nationwide | Nationwide |
| Demographic | 20s to 40s, household income 6 million yen or more, DINKs or no children | All ages, any household income | 40s to 60s, homeowners |
| Psychographic | See the dog as family. Insist on organic and additive-free | Want "cheap and good enough quality" | Want to extend their dog's healthy lifespan |
| Behavioral | Spend 10,000 yen or more per month on pet-related items. Gather information on social media | Buy at home improvement stores. Compare prices | Value veterinarian recommendations. Prefer subscriptions |

**Targeting**:
- Selected segment: Segment 1 "Health-conscious owners"
- Reason for selection: High unit price and high repeat rate expected. Our ability to source organic ingredients becomes a strength
- Market size: About 80 billion yen (premium pet food market)
- Growth potential: 8% annual growth (trend of pets as family members)
- Competitive situation: Major players concentrate on the low to mid price range. The premium range is dominated by imported brands with few domestic brands
- Fit with own strengths: We have a proprietary sourcing network for domestic organic ingredients. We have veterinarian-supervised formulation technology

**Positioning**:
- Point of differentiation: "100% domestic organic ingredients, veterinarian supervised"
- Positioning statement: "For urban owners who are serious about their dog's health, our brand is the only premium dog food that combines 100% domestic organic ingredients with veterinarian-supervised nutritional design, because we contract directly with 30 domestic organic farms and a team of animal nutrition experts designs every recipe."

### Common mistakes
1. **Segmentation by demographics only**: A division by attributes alone, such as "women in their 30s," can't capture differences in behavior and psychology. Always combine psychographic and behavioral variables
2. **Making the target "everyone"**: "Loved by a wide range of people" is not a strategy. The courage to decide which segments to give up is what matters
3. **Positioning with no customer in it**: "We are No. 1 in technology" is the company's point of view. Positioning defines "what we are to the customer"

### Tips
- **Draw a Positioning Map**: Build a map on two axes customers care about (e.g., price × quality, convenience × expertise) and plot yourself and competitors. Empty areas are opportunities
- **Actually test the statement**: Show the positioning statement to 5 to 10 target customers and verify whether they feel "this is for me"
- **Check consistency with the 4Ps**: Confirm that the positioning decided in STP does not contradict Price, Product, Place and Promotion

### Next steps
- **Persona** (`/customer` 01) to draw a concrete picture of the selected target
- **TAM/SAM/SOM** (`/customer` 08) to quantify the market size of the selected segment
- **Macro environment and industry analysis** (`/market`) to verify the attractiveness of the market
- **Strategy and business model design frameworks** (`/strategy`) to design the marketing mix such as 4P/4C

## 08. TAM/SAM/SOM
**Purpose**: Estimate market size at three levels and quantify the growth potential of the business. Produce the numbers that underpin investment decisions and business plans

**When to use**: Writing a business plan, pitch decks for investors, Go/No-Go decisions on new businesses, building the basis for budgeting

**Template**:
| Level | Definition | Estimate | Basis of calculation |
|-------|------|-------|---------|
| **TAM** (Total Addressable Market) | Maximum obtainable market size | | |
| **SAM** (Serviceable Available Market) | Market size the company can reach | | |
| **SOM** (Serviceable Obtainable Market) | Market size realistically expected to be won | | |

**Estimation approaches**:
| Method | Description | Advantages | Disadvantages |
|------|------|---------|----------|
| Top-down | Whole market → narrow down by conditions | Fast, macro view | Tends to be optimistic |
| Bottom-up | Build up from unit price × number of customers × frequency | Realistic, persuasive | Takes time |
| Value theory | Work backward from the value delivered | Effective for creating new markets | No precedent, hard to verify |

### Worked example (B2B AI meeting-minutes SaaS)

**Top-down estimate**:
| Level | Definition | Estimate | Basis of calculation |
|-------|------|-------|---------|
| **TAM** | Global AI meeting-minutes and meeting support market | 500 billion yen | The AI meeting-minutes portion of the global meeting tech market. See research firm report (2025) |
| **SAM** | Japanese domestic AI meeting-minutes market for companies with 100+ employees | 80 billion yen | About 50,000 domestic companies × average annual contract of 1.6 million yen (100 people × 1,333 yen per month) |
| **SOM** | Expected to win within 3 years of launch | 4 billion yen | 5% of SAM (2,500 companies). Estimated from early adoption rates of similar SaaS. Sales team of 10 approaches 800 companies a year, 10% close rate, 3-year cumulative |

**Bottom-up estimate (verifying SOM)**:
- Monthly unit price: 1,333 yen per user (16,000 yen per year)
- First-year target customers: 300 companies (average 100 users per company)
- First-year revenue: 300 companies × 100 people × 16,000 yen = 480 million yen
- Year 3 projection: 2,500 customers, annual revenue 4 billion yen (consistent with SOM)

### Common mistakes
1. **Inflating TAM**: Bringing in a higher-level figure like "Japan's IT market is X trillion yen" and including parts unrelated to your business. TAM is the market size "if your product theoretically replaced everything"
2. **SOM without basis**: The "should" in "we should be able to take 5% share" is not persuasive. Work backward from concrete resources such as sales headcount, close rate and marketing budget
3. **Calculating once and never updating**: Markets fluctuate. Check the gap against actual data every quarter and revise the estimate

### Tips
- **Always verify with both top-down and bottom-up**: If the two figures diverge widely, there is a problem somewhere in the assumptions
- **Cite sources**: Back it up with third-party data such as research firm reports, government statistics and industry association data
- **Show the SAM → SOM conversion rate in multiple scenarios**: Estimating three patterns, optimistic, base and conservative, earns the trust of investors and stakeholders
- **Work backward from competitors' share**: Estimate market share from the revenue of listed competitors and verify whether your own target share is reasonable
- **Show the TAM growth rate too**: Beyond a static number, showing the annual growth rate conveys the attractiveness of the market

## How to run the conversation

### Step 1: Listening
Review the user's input and establish the following information. If anything is missing, ask questions to fill the gaps.

- **Target business**: What product or service. B2B or B2C
- **Current phase**: Idea stage / validating MVP / growth stage / mature stage
- **Purpose**: Acquiring new customers / deepening existing customers / estimating market size / changing target / preventing churn, etc.
- **Available data**: Customer database / survey results / interview records / sales data / access logs, etc.
- **Use of the output**: Internal discussion / executive meeting materials / investor pitch / planning marketing initiatives, etc.

### Step 2: Framework selection
Propose the best framework for the purpose. Use the following table as a reference.

| Purpose | Recommended framework | Supporting framework |
|------|-----------------|-----------------|
| Clarify the customer picture | Persona (01) | Empathy Map (02) |
| Understand the customer's real needs | Jobs to Be Done (JTBD) (04) | Empathy Map (02) |
| Improve the service experience | Customer Journey Map (03) | Empathy Map (02) |
| Prioritize customers | RFM Analysis (06) | Pareto Analysis (05) |
| Define the target | STP (07) | Persona (01) |
| Know the market size | TAM/SAM/SOM (08) | STP (07) |
| Optimize sales composition | Pareto Analysis (05) | RFM Analysis (06) |

When combining multiple frameworks, it is recommended to proceed in the order above.

### Step 3: Fill in the template interactively
- Don't ask about every item at once. Ask about 3 to 4 items at a time, in stages
- Follow up on the user's answers with "why?" and "specifically?" to dig deeper
- For items without data, fill in a hypothesis and mark it "to be verified"
- If the user is stuck, offer hints by showing general industry trends or examples from other companies

### Step 4: Complete and output
- Output the completed worksheet in Markdown
- State 3 to 5 implications (So What?) drawn from the analysis
- Propose concrete next actions (Next Steps)
- Where appropriate, suggest using related frameworks (`/strategy`, `/market`, `/problem`, `/idea`, `/execution`, etc.)

### Step 5: Verification and improvement
- For items filled in as hypotheses, propose verification methods (interview design, survey questions, etc.)
- Propose a regular update cycle (monthly / quarterly / semi-annually)
- Organize who the analysis results will be shared with and how they will be used
