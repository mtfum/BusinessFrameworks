# 戦略立案・ビジネスモデル設計フレームワーク

## 01. PPM（プロダクト・ポートフォリオ・マネジメント）
**目的**: 事業や製品を「市場成長率」と「相対的市場シェア」の2軸で分類し、資源配分を最適化する
**テンプレート**:
|  | 市場シェア：高 | 市場シェア：低 |
|---|-------------|-------------|
| **成長率：高** | ★花形（Star） | ？問題児（Question Mark） |
| **成長率：低** | 💰金のなる木（Cash Cow） | 🐕負け犬（Dog） |

**事業配置**:
| 事業名 | 市場成長率 | 相対シェア | 象限 | 投資方針 |
|-------|----------|----------|------|---------|
| | | | | |

## 03. ポジショニングマップ
**目的**: 競合との位置関係を2軸のマップで可視化し、差別化ポイントや空白地帯を発見する
**テンプレート**:
```
        軸Y（高）
          ↑
    ●B    |    ●C
          |
──────────┼──────────→ 軸X（高）
          |
    ●A    |    ●自社
          |
        軸Y（低）
```
- 軸X:（例：価格 低→高）
- 軸Y:（例：機能 少→多）
- プロットする企業/製品: 

**使い方**: 軸の選び方が肝。顧客の購買決定要因（KBF）を軸にする。

## 04. ブルーオーシャン戦略（戦略キャンバス）
**目的**: 競争のない未開拓市場を創造するための差別化と低コストの同時追求
**テンプレート（ERRCグリッド）**:
| アクション | 要素 | 具体策 |
|----------|------|-------|
| **Eliminate**（取り除く） | | |
| **Reduce**（減らす） | | |
| **Raise**（増やす） | | |
| **Create**（付け加える） | | |

**戦略キャンバス**: 競合の価値曲線と自社の新しい価値曲線を比較する

## 05. ビジネスモデル・キャンバス（BMC）

**テンプレート**:
| ブロック | 内容 |
|---------|-----|
| **KP** 主要パートナー | |
| **KA** 主要活動 | |
| **KR** 主要リソース | |
| **VP** 価値提案 | |
| **CR** 顧客との関係 | |
| **CH** チャネル | |
| **CS** 顧客セグメント | |
| **C$** コスト構造 | |

**使い方**: まずVP（価値提案）とCS（顧客セグメント）を埋め、そこから他のブロックを展開する。

## 07. 4P分析（マーケティング・ミックス）
**目的**: マーケティング施策をProduct・Price・Place・Promotionの4要素で設計する
**テンプレート**:
| 4P | 自社 | 競合A | 競合B |
|----|-----|------|------|
| **Product**（製品・サービス） | | | |
| **Price**（価格・料金体系） | | | |
| **Place**（流通・販売チャネル） | | | |
| **Promotion**（販促・コミュニケーション） | | | |

**使い方**: 4Pは売り手視点。顧客視点の4C（Customer Value, Cost, Convenience, Communication）と対比すると深まる。

## 08. AIDMA
**目的**: 消費者の購買心理プロセスを5段階でモデル化し、各段階の施策を設計する
**テンプレート**:
| 段階 | 顧客の状態 | 施策 | KPI |
|------|----------|------|-----|
| **A**ttention（注意） | 知らない→知る | | |
| **I**nterest（興味） | 知る→興味を持つ | | |
| **D**esire（欲求） | 興味→欲しくなる | | |
| **M**emory（記憶） | 欲しい→覚えている | | |
| **A**ction（行動） | 覚えている→買う | | |

**補足**: デジタル時代にはAISAS（Search, Share）やAISCEAS等の派生モデルも検討する。

---

## 09. コア・コンピタンス分析
**目的**: 自社の中核的な能力を特定し、それを軸にした戦略を構築する
**テンプレート**:
| 候補となる能力 | 顧客価値への貢献 | 競合との差別化 | 展開可能性 | 評価 |
|-------------|--------------|------------|----------|------|
| | 高/中/低 | 高/中/低 | 高/中/低 | |

**3つの条件**:
1. 顧客に認知される価値を提供できる
2. 競合に模倣されにくい
3. 複数の市場・製品に展開できる

---

## 10. スキーム図
**目的**: ビジネスの仕組み（ヒト・モノ・カネ・情報の流れ）を図示して関係者間の構造を可視化する
**テンプレート**:
```
[プレイヤーA] ──サービス提供──→ [プレイヤーB]
      ↑                            │
      │                            ↓
   対価（手数料）              対価（利用料）
      │                            │
      └─────── [プレイヤーC] ←──────┘
```

**記載要素**: 登場人物（ステークホルダー）、提供価値、金銭の流れ、情報の流れ、契約関係
