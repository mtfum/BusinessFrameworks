## 04. VRIO分析
**目的**: 自社の経営資源が持続的競争優位の源泉になるか評価する
**テンプレート**:
| 経営資源 | Value（価値） | Rarity（希少性） | Imitability（模倣困難性） | Organization（組織） | 競争優位の状態 |
|---------|:-----------:|:--------------:|:--------------------:|:-----------------:|------------|
| 資源1 | ○/× | ○/× | ○/× | ○/× | |
| 資源2 | ○/× | ○/× | ○/× | ○/× | |
| 資源3 | ○/× | ○/× | ○/× | ○/× | |

**判定**: V×→競争劣位 / V○のみ→競争均衡 / VR○→一時的優位 / VRI○→持続的優位 / VRIO全○→最大優位

## 05. SWOT分析
**目的**: 内部環境（強み・弱み）と外部環境（機会・脅威）を整理する
**テンプレート**:
|  | プラス要因 | マイナス要因 |
|---|---------|----------|
| **内部環境** | **Strengths（強み）** | **Weaknesses（弱み）** |
| | ・ | ・ |
| **外部環境** | **Opportunities（機会）** | **Threats（脅威）** |
| | ・ | ・ |

**使い方**: PEST分析→3C分析の後に行うと精度が上がる。クロスSWOTに展開して戦略を導く。

---

## 06. クロスSWOT
**目的**: SWOT分析の4要素を掛け合わせて具体的な戦略オプションを導出する
**テンプレート**:
|  | **機会（O）** | **脅威（T）** |
|---|------------|------------|
| **強み（S）** | SO戦略（積極攻勢） | ST戦略（差別化） |
| | ・ | ・ |
| **弱み（W）** | WO戦略（弱点克服） | WT戦略（防衛・撤退） |
| | ・ | ・ |

**使い方**: まずSO戦略（強み×機会）を最優先で検討し、次にWT戦略（弱み×脅威）でリスクを把握する。

---

## 対話の進め方

1. AskUserQuestionで分析対象の業界・企業・目的をヒアリング
2. 最適なフレームワークを提案
3. テンプレートを提示し、項目ごとに対話的に埋めていく
4. 完成したワークシートをMarkdownで出力
5. 顧客分析や戦略立案フレームワークへの接続を提案
