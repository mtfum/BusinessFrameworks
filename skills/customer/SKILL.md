## 02. 共感マップ
**目的**: 顧客の内面（思考・感情）と外面（行動・環境）を6つの視点で把握する
**テンプレート**:
| 視点 | 内容 |
|------|-----|
| **Think & Feel**（考え・感じていること） | |
| **See**（見ているもの） | |
| **Hear**（聞いていること） | |
| **Say & Do**（言動） | |
| **Pain**（痛み・不満） | |
| **Gain**（得たいもの・望み） | |

**使い方**: ペルソナと組み合わせて使う。Pain→Gainの流れで自社の提供価値を検討する。

## 04. ジョブ理論（Jobs to be Done）
**目的**: 顧客が「片付けたいジョブ（用事）」を軸に、真のニーズを発見する
**テンプレート**:
| 項目 | 内容 |
|------|-----|
| **状況（When...）** | どんな状況で |
| **動機（I want to...）** | 何をしたくて |
| **期待成果（So that...）** | どうなりたいのか |

**ジョブの種類**:
- 機能的ジョブ（実用的な目的）:
- 感情的ジョブ（感じたい気持ち）:
- 社会的ジョブ（周囲からどう見られたいか）:

**使い方**: 「顧客はドリルが欲しいのではなく、穴が欲しい」という視点。既存の解決策ではなくジョブに着目する。

## 05. パレート分析（ABC分析）
**目的**: 全体の成果の大部分を生み出す少数の要因を特定する（80:20の法則）
**テンプレート**:
| ランク | 項目 | 数値 | 構成比 | 累積構成比 | 分類 |
|-------|------|-----|-------|----------|------|
| 1 | | | | | A |
| 2 | | | | | A |
| 3 | | | | | B |
| ... | | | | | C |

**分類基準**: A（累積〜70%）、B（〜90%）、C（〜100%）

## 06. RFM分析
**目的**: 顧客を購買行動の3指標でセグメント化し、優先度を判定する
**テンプレート**:
| 顧客 | Recency（最終購買日） | Frequency（購買頻度） | Monetary（購買金額） | スコア | セグメント |
|------|-------------------|-------------------|-------------------|-------|----------|
| | 高/中/低 | 高/中/低 | 高/中/低 | | |

**代表セグメント**: 優良顧客（RFM全高）、離反リスク（R低・FM高）、新規有望（R高・FM低）

## 08. TAM／SAM／SOM
**目的**: 市場規模を3段階で推計し、事業の成長ポテンシャルを定量化する
**テンプレート**:
| レベル | 定義 | 推計値 | 算出根拠 |
|-------|------|-------|---------|
| **TAM**（Total Addressable Market） | 獲得可能な最大市場規模 | | |
| **SAM**（Serviceable Available Market） | 自社がアプローチ可能な市場規模 | | |
| **SOM**（Serviceable Obtainable Market） | 実際に獲得見込みの市場規模 | | |

**使い方**: 投資家向けピッチや事業計画で必須。トップダウン（全体→絞込み）とボトムアップ（単価×数量）の両面で検証する。
